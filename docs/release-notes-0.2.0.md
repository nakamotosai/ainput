# ainput 0.2.0

本地优先的 Windows 语音听写。按住 **CapsLock** 说话，松开即把文字贴进当前窗口。可选 AI 改写（用你自己的 OpenAI 兼容接口）。

## 两种安装方式

- **安装包（推荐）**：`ainput-0.2.0-setup.exe` — 双击安装，含开始菜单、可选开机自启、卸载器。每用户安装，无需管理员。
- **便携绿包**：`ainput-0.2.0-win64.zip` — 解压即用，不写注册表，绿色无痕。

## 本版重点

- **隐私**：默认不再保存原始录音；发布版日志不含你的听写文本（仅字符数）。
- **省电**：空闲 30 秒自动释放麦克风，不再阻止电脑自动休眠。
- **默认键改为 CapsLock**（与文档/官网一致），托盘可自定义。
- 体积优化：便携包不再打包用不到的 GPU 库，下载体积明显更小。

## 已知

- 未做代码签名：首次运行 Windows 可能弹「已保护你的电脑」，点「仍要运行」即可。

## 校验

```powershell
Get-FileHash .\ainput-0.2.0-win64.zip -Algorithm SHA256

```
